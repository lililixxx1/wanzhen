# T003 · M0-02 六兵种数据与单 lane 移动

- 周位：W1
- 前置：T002
- 目标：6 兵种静态数据表 v0 + 双方布阵 + 单 lane 一维推进 + 间距碰撞。

## 范围内

- 6 兵种数据表 v0：名称 / hp / 攻击力 / 攻速(tick) / 移速 / 体型(碰撞半径) / **克制类别**（重甲 / 轻甲 / 无甲三类）。数据表以 const 表或独立数据文件落码（实验场 T009 须能读取）；初值自拟、标注「平衡初值，实验场回归对象」。
- 克制表 v0：三类单环，**方向以报告 3.1 为准（实现前先读 docs/ 报告对应节）**；克制倍率初值 ×1.5 / ×1.0 / ×0.67（自拟可调）。
- 布阵：双方对称布阵接口（seed + 兵种构成清单 → 确定性排布）。
- 单 lane 一维移动：向敌方推进；与最近敌方单位贴身（间距 = 双方半径和）即停止；位置为定点数或浮点（**浮点则累加顺序固定：每 tick 单次增量、按索引序结算**——5.2 纪律）。

## 范围外

攻击/伤害/死亡（T004）；多 lane；地形。

## 验收断言

1. check 0 警告；同 seed 跨进程布阵快照（全单位位置表）逐位一致。
2. 构造对拍用例：无敌方时全速推进 N tick 的位置 = 初值 + 速度×N（定点/浮点口径注明）；贴身停使用例距离稳定不再变化。
3. 6 兵种 × 克制三类的倍率查询全组合正确（单测穷举）。
