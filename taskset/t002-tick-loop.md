# T002 · M0-01 最小确定性 tick 循环（验收④地基）

- 周位：W1（2026-10-05 起）
- 前置：T001
- 目标：headless 确定性模拟地基——固定步进 tick（30Hz 名义，tick 为纯计数、量测与回放按 tick 推进，**不依赖挂钟**）、索引数组单位容器（容量预留、遍历序 = 索引序）、确定性 RNG、每 tick 末状态哈希输出。

## 范围内

- tick 推进循环与 tick 计数状态；空单位容器即可跑通。
- 确定性 RNG 选型：**优先零依赖自实现**（SplitMix64 / xoshiro256** 族；bevy-ai-workflow 仓 PIT-M-002 教训——参考向量必须实测对齐后方可引用）；禁用依赖系统熵源的 RNG；seed 注入接口。
- 状态哈希：按单位索引固定序折叠（FNV-1a 或同类自实现），输出含 rng_state 与 tick 计数。
- 单元测试：RNG 统计烟雾（值域分布粗检）。

## 范围外（不做）

- 兵种/战斗/移动逻辑；并行；渲染；任何 bevy 调度 API（如需引入 bevy_ecs schedule 须先查证 0.19 官方文档并上报选型）。

## 验收断言

1. `cargo check --workspace` 0 警告；单测全绿。
2. 同 seed 两次独立进程运行（各 ≥1,800 ticks）终局哈希逐位一致；不同 seed 哈希不同。
3. 10,000 空单位容器 × 1,800 ticks 壁钟 < 1s（release，能力烟雾，非正式量测）。
4. RNG 参考向量实测对齐记录入档（或自实现统计烟雾数据）。
