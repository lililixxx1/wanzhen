# T022 M5-05 挑战预设（席位 7）

- 周位：W3

- 类型：代码（数据化预设 + 断言接入；轻量审核轮）
- 预估：3h

## 范围内

- **≥3 个预设挑战**（备忘录 §三：挑战 = 构成/参数 + 期望终局判定的**数据化定义**；例举方向——以少胜多、克制极端例；终局可断言完成）。
- 每挑战三件套：构成 + 参数 + 期望终局断言（数据档）；挑战判定接入 `game.run_tests` 面（挑战通过 = 判定面 pass 项）。
- 判定行代码生成（不手算——沿 M0 纪律）。

## 范围外

- 挑战编辑 / 排行榜 / 成就（蔓延面预裁）。
- 新模拟机制（挑战只用既有参数面可表达的构型）。
- 挑战难度调优迭代（初值即交付，平衡性不设验收线）。

## 验收断言

1. ≥3 挑战预设数据化在档（构成/参数/期望终局断言三件套逐条）。
2. 每挑战经 `game.run_tests`（挑战判定面）断言通过——判定行代码生成。
3. 期望终局与实测终局一致可复跑（预设含固定 seed 则逐位复现）。
4. check 0 警告；sim 零改动。
