# T004 新黄金值实测固化过程（PIT-M-002 流程：占位 0 → 实测 → 回填 → 复跑全绿）

## 0) 旧黄金失效留痕

- T003 旧黄金：`0xf2b85bd4727c2d45`（= 17489830120905256261，默认构成 deploy、
  seed 42、1800 ticks 终局哈希，见 docs/evidence/t003/golden.txt）。
- 失效原因（两项叠加，均为 T004 派工单 D5/D7 规定动作）：
  1. **哈希折叠扩展（D7）**：每单位折叠序列由
     `[alive 1B + kind 1B + side 1B + x 8B LE]` 扩展为
     `[alive 1B + kind 1B + side 1B + hp 4B LE + cd 4B LE + x 8B LE]`——
     布阵快照哈希即已改变（deploy 快照 0x22bce4da752220de → 0xe2706f0b91a2be8e，
     见 crossproc.txt §5；T003 时该快照仅为证据留档、非黄金锚）。
  2. **战斗行为上线（D1~D6）**：cd 冷却、伤害、墓碑移除改变状态演化本身。
- 附带核验：T002 黄金锚 `0xd3b6408fd46c2008`（units=0）**原值保持**——
  units=0 时折叠序列不含单位段，D7 扩展不影响（golden_hash_seed42_units0_1800ticks
  测试 + CLI 复核双绿，见 crossproc.txt §5）。
