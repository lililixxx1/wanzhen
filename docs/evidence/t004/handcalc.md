# T004 手算推演表（验收 2：手算对拍 ≥3 例）

口径：Q32.32 定点（1m = ONE = 4294967296）；伤害 = atk × 克制倍率 / 65536（i32 截断）；
倍率按 T003 锁定克制表（重甲克轻甲、轻甲克无甲、**无甲克重甲**、反向被克 ×43690、同类中性）。
每 tick 阶段序（D5）：移动 → 战斗（cd 统一衰减 → 索引序逐单位判定）→ tick 末清墓碑。
射程条件：|dx| ≤ 半径和 + 0.2m（D3）。

## 例 1：红盾兵 vs 蓝长矛兵，克制互殴到击杀（单测 handcalc_pair_counter_fight_to_kill）

构造：idx0 红盾兵 x=0.5m（r=0.5，speed 0.05，atk 8，interval 30，Heavy，hp 120）；
idx1 蓝长矛兵 x=1.5m（r=0.5，speed 0.10，atk 10，interval 30，Light，hp 80）。
|dx| = 1.0m = 半径和 → 双方 gap=0 **全程零移动**。
伤害：盾兵(Heavy)→长矛(Light) 克制 ×98304 → 8×98304/65536 = **12**；
长矛(Light)→盾兵(Heavy) 被克 ×43690 → 10×43690/65536 = **6**。
双方 interval=30：击点 t=1, 31, 61, 91, 121, 151（击后 cd=30，每 tick 开头 -1，t+30 开头恰 0）。

| tick | 移动 | 战斗事件 | 战斗后快照（hp / cd） |
|---|---|---|---|
| 1 | 双方不动（gap=0） | 红击蓝（-12）、蓝击红（-6） | 蓝 68/30，红 114/30 |
| 2..30 | 不动 | 无（cd 衰减） | 每 tick cd-1 |
| 31 | 不动 | 红击蓝、蓝击红 | 蓝 56/30，红 108/30 |
| 61 | 不动 | 红击蓝、蓝击红 | 蓝 44/30，红 102/30 |
| 91 | 不动 | 红击蓝、蓝击红 | 蓝 32/30，红 96/30 |
| 121 | 不动 | 红击蓝、蓝击红 | 蓝 20/30，红 90/30 |
| 151 | 不动 | 红击蓝、蓝击红 | **蓝 8/30，红 84/30**（断言快照 ✓） |
| 152..180 | 不动 | 无（cd 衰减） | t=181 开头双方 cd 恰 0 |
| 181 | 双方不动（蓝尚存活，先动后打） | **索引序红先击：蓝 8-12 = -4 → 墓碑**；轮到蓝：已死跳过（不反击） | tick 末 retain → count=1；红 84/30，x 仍 0.5m ✓ |
| 182..185 | 红无阻挡全速 0.05/tick | 无（红 cd 衰减） | t=185：红 x = 0.5+4×0.05，cd = 30-4 = **26** ✓ |

终局：蓝长矛于 t=181 死亡清除；红盾兵 hp=84 存活。

## 例 2：等距目标决胜——B 不被选中（单测 handcalc_equal_distance_target_tiebreak_by_index）

构造：idx0 红民兵 x=0；idx1 蓝民兵 A x=0.8m；idx2 蓝民兵 B x=-0.8m。
民兵：r=0.4，speed 0.09，atk 6，interval 20，hp 50，全 Unarmored（中性 ×65536 → 伤害 = atk = 6）。
布阵位口径：红-A 距 0.8m = 半径和恰贴身；红-B 距 0.8m 与 A 等距（B 在红背后）。
派工单口径按布阵位记「0.8=0.8 平局 → idx1 决胜」；实现口径（D5：先动后打）下 B 在
t=1 移动阶段已全速后撤至 0.89m，红索敌时 A 严格最近——两种口径结论一致：**红打 A 不打 B**。

| tick | 移动 | 战斗事件 | 战斗后快照 |
|---|---|---|---|
| 1 | B：-x 向前方无人 → 全速退 0.09 → x=-0.89；红/A 贴身 gap=0 不动 | 红：最近敌方 = A（0.8）→ 击 A（-6）；A：击红（-6）；B：距 0.89 ≤ 1.0（0.4+0.4+0.2）→ 击红（-6） | **红 38/20，A 44/20，B 50/20**；B.x = -0.8-0.09 ✓（B hp=50 = 未被红选中之决胜证据） |
| 2 | B 退至 0.98（仍 ≤1.0 但 cd=19 ≠ 0，不击） | 无 | — |
| 3..20 | B 每 tick 退 0.09（t≥3 起距离 >1.0 出射程）；红/A gap=0 不动 | 无（cd 衰减） | — |
| 21 | B 退至 -(0.8+21×0.09)=-2.69 | 红击 A（-6）、A 击红（-6）；B 距 2.69 出射程不击，cd 已自然衰减至 0 保持 0 | **红 32/20，A 38/20，B 50/0**；B.x = -(0.8+21×0.09) ✓ |

## 附 G：盾兵-民兵 3m 相向对局重推演（改造 G 的期望值依据）

构造：idx0 红盾兵 x=0、idx1 蓝民兵 x=3m，相向。
合闭 0.05+0.09 = 0.14 m/tick；伤害：盾兵(Heavy)→民兵(Unarmored) **被克** ×43690 →
8×43690/65536 = **5**/击（interval 30）；民兵(Unarmored)→盾兵(Heavy) **克制** ×98304 →
6×98304/65536 = **9**/击（interval 20）。
（派工单 G 原用 12/击与 3/击——分别是 Heavy→Light 与 Unarmored→Light 的倍率，
即把民兵当作轻甲方向结算；与锁定表「无甲克重甲」方向相反，已上报。）

- T0（首次可击 tick）：移动后 |dx| 首次 ≤ 0.9+0.2 = 1.1m。合闭 0.14/tick：
  t=13 末距 1.18 > 1.1；t=14 末距 1.04 ≤ 1.1 → **T0 = 14**。
- 盾兵击点：14, 44, 74, 104, 134, 164, 194, …（interval 30）；
  民兵击点：14, 34, 54, 74, 94, 114, 134, 154, 174, 194, …（interval 20）。
- t=200 时：蓝民兵被击 7 次 × 5 = 35 → hp = **15**；红盾兵被击 10 次 × 9 = 90 → hp = **30**。
  双方均存活 → count=2（派工单原断言「t=200 蓝已移除、红 hp=102」按错误倍率推得，
  无法在锁定表下成立，按实推值 15/30 落断言，已上报）。
- 首亡推演：红盾兵 hp 120 / 9 = 13.3 → 第 14 击于 t = 14+13×20 = **274** 死亡
  （t=274 非盾兵击点：274-14=260 非整 30 倍 → 盾兵先死于民兵之手，索引序不影响结论）；
  蓝民兵 hp 50 / 5 = 10 → 第 10 击于 t = 14+9×30 = 284，晚于红。故 t=101..120 窗口内
  双方位置稳定成立。

## 附 H：重骑-民兵 20m 对局存活推演（改造 H 的 hp 垫高依据）
