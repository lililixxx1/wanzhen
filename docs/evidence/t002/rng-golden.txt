     17057574109182124193, 18295552978065317476, 14199186830065750584,
     13267978908934200754, 15679888225317814407]

    python 复算 = 15255451774252490760 = 0xd3b6408fd46c2008
    Rust 实测   = 15255451774252490760 = 0xd3b6408fd46c2008
    match = True
  复算备注：首轮 python 复算误用「打印 first8 后的同一 RNG 实例」续跑（共 1808 次
  消耗）得 0x64a9bd58619f5433 不符——属复算脚本状态复用失误，非 Rust 实现问题；
  改为全新实例后完全一致（match=True）。Rust 侧实现未因此做任何改动。
