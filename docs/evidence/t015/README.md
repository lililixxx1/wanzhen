## 核心判定（summary.md 代码生成，人工只解读）

  581×/1846×，距止损线 2µs 裕度 ≥18×。

  （T007：7.22×/9.42×）。**低于预注册区间（D10 登记 1.5~2.5×），如实披露**，机理见下。
- **③ 极限十万：由「不保留」翻转为「保留」**——C(100000) 单线程外推 15.46ms/tick
  ≤ 22ms 极限预算（b 系数 3.997→0.000918：O(N²) 项已消，成本近线性 a=62.8ns/单位/tick）。
- ⑥ 内存未重跑（无内存行为变更，D10 预登记；summarize 披露行在档）。

## ② 加速比结构性归因（预注册 D10 + 实测复核）

1. **可并行内容已被本卡删除**：T007 时代意图 O(N²) 扫描占每 tick 耗时 ~97% 且可
   并行（实测 7.22×）；优化后每 tick 仅剩 O(N log N)/O(N) 管线，其中可并行部分
   （分片排序 + 查询）占比骤降——本次 Amdahl 拟合 @10k：c1=630909ns、c2=61780ns
   （可并行内容占比 ≈ 8.9%，R²=0.19 因短局噪声）。
2. **串行下限**：FNV-1a 状态哈希为逐字节依赖链（hash.rs 逐字节实现，19B/单位；
   XOR×乘法无分段合并闭式，精确并行不可达）+ apply 阶段索引序串行语义（clamp 读
   前方者最新位置 / 墓碑即时生效，黄金锚语义锁定）+ 串行归并/扫掠。
3. **池开销实测吞掉残余并行收益**：12 线程档实测 ≈ 单线程（1.00×）——map_chunks
   每次派发的 Arc 克隆（~0.3~0.8MB/tick）与通道往返开销与可并行收益同量级；
   1k 档净负收益（0.40×）。
4. **上限推演**：即便池开销归零、其余全部完美并行，S(12)@10k 上限 ≈
   1/(0.19+0.81/12) ≈ 3.9×（哈希链独占串行 19% 时**理论上限已低于 4× 线**；
   P2-1 勘误：初稿误写 4.1×，审核轮 python 复算 3.883495）——加回必串行
   apply 后 ≈2.6~3.5×。**轮二（t016：并行归并/扫掠、池开销削减）无法以诚实
   手段把 ② 拉回 ≥4×**；同时 ①③ 显示预算侧已全满足（常态 8ms：10k 实测 0.71ms；
   极限 22ms：100k 外推 15.5ms——均单线程即达）。② 的判据意图（防「串行快但无
   并行余量」）在当前量级下已被 ①③ 实质覆盖，字面与意图分离——**owner 裁决点**，
   本卡只产数据与判定，不自行放行（任务卡 D10 预登记同一结论）。
